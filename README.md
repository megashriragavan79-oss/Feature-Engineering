# Feature Engineering & Preprocessing Pipeline

Files:
- `feature_engineering_preprocessing_pipeline.ipynb`: requested Jupyter notebook
- `feature_engineering_preprocessing_pipeline.py`: exported code
- `customer-churn-training.csv`: supplied demonstration dataset

Run:
1. Install: `pip install pandas numpy matplotlib seaborn scikit-learn joblib`
2. Open the notebook in Jupyter or Google Colab.
3. Keep the CSV in the notebook working directory.
4. Run all cells in order.

The supplied dataset has 12 rows only. This is suitable for demonstrating the pipeline structure, not for reliable model validation or production use.
